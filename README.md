# Веб-разработка: задания по ООП

| № | Задание | Язык | Файл |
|---|---------|------|------|
| 1 | Классы `User` и `SuperUser`: приватные поля, геттеры и сеттеры, сравнение по `grade`, счётчики экземпляров | JavaScript | [user.js](user.js) |
| 2 | Библиотека: абстрактный `Publisher`, `Book`, `Magazine`, интерфейс `Reception`, `Reader`, `Library` | JavaScript | [library.js](library.js) |
| 3 | Плоттер, переписанный из процедурного стиля в ООП: `Plotter`, интерфейс `Logger`, `LogToConsole` | TypeScript | [plotter.ts](plotter.ts) |

## Запуск

Нужен [Node.js](https://nodejs.org).

```bash
node user.js
node library.js
npx tsx plotter.ts
```
