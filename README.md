# Веб-разработка: задания по ООП

| № | Задание | Язык | Файл |
|---|---------|------|------|
| 1 | Классы `User` и `SuperUser`: приватные поля, геттеры и сеттеры, сравнение по `grade`, счётчики экземпляров | JavaScript | [task1/user.js](task1/user.js) |
| 2 | Библиотека: абстрактный `Publisher`, `Book`, `Magazine`, интерфейс `Reception`, `Reader`, `Library` | JavaScript | [task2/library.js](task2/library.js) |
| 3 | Плоттер, переписанный из процедурного стиля в ООП: `Plotter`, интерфейс `Logger`, `LogToConsole` | TypeScript | [task3/plotter.ts](task3/plotter.ts) |

## Запуск

Нужен [Node.js](https://nodejs.org).

```bash
node task1/user.js
node task2/library.js
npx tsx task3/plotter.ts
```

Или через npm-скрипты:

```bash
npm run task1
npm run task2
npm run task3
```
